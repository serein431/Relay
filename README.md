# Relay

Relay 用来分享 Claude Code 和 ChatGPT 的开发会话。

发送者选中一段会话后，Relay 会把聊天记录、项目说明，以及用户选择的 Git 修改放进一个加密分享包。接收者打开链接，就能先在浏览器里查看完整聊天记录；需要继续处理代码时，再用 Relay 恢复到本机目录，并从 Claude Code 或 ChatGPT 开始一个新任务。

它适合这样的情况：一个人已经和 AI 处理了很久，另一个人不想重新询问项目背景，也不想靠一份临时总结猜测之前做过什么。

## 可以分享什么

- 用户和助手的消息。
- 已经发生过的工具调用和结果。这些内容只能查看，不会再次执行。
- `AGENTS.md`、`CLAUDE.md` 等已经出现在会话中的项目说明。
- 系统、架构和已发现工具的简要信息。
- Git 中尚未推送的提交、暂存修改、未暂存修改，以及用户选中的新文件。

发送前可以逐项检查和取消选择。Relay 发现疑似密钥、连接串或私钥时，会要求再次确认。

## 接收者需要安装 Relay 吗

不一定。

接收者直接打开分享链接，可以在浏览器中：

- 查看完整聊天记录。
- 搜索消息、工具名称和正文。
- 按“对话”或“工具记录”筛选。
- 复制单条记录。
- 查看、复制或下载 `HANDOFF.md`。
- 下载原始 `.relaypack` 文件。

以下操作需要 Relay 桌面应用：

- 恢复分享包中的 Git 修改。
- 创建新的本机工作目录。
- 从交接目录打开 Claude Code。
- 在官方 ChatGPT 应用中打开一个新任务。

## 怎么使用

### 发送分享

1. 打开 Relay，从项目列表中选择一段 Claude Code 或 ChatGPT 会话。
2. 阅读完整聊天记录，选择要分享的内容。
3. 如果当前目录是 Git 仓库，可以继续选择要附带的本地修改；普通文件夹也可以只分享会话。
4. 检查最终内容后生成分享链接。
5. 把完整链接发给接收者。

链接中 `#k=` 后面的内容是解密密钥。缺少这一段，接收者无法查看分享内容。

### 浏览器查看

接收者打开完整链接后，页面会下载密文，并在当前浏览器中解密。页面不会连接第三方服务。

分享服务器提供的网页代码理论上可以读取地址中的密钥。内容包含私有代码、账号信息或其他敏感资料时，建议双方都使用 Relay 桌面应用，并通过可信方式传递分享包和密钥。

### 在本机继续处理

1. 在 Relay 的“接收分享”页面粘贴完整链接，或选择本机 `.relaypack` 文件并输入密钥。
2. 先查看会话、项目说明和文件变化。
3. 含 Git 内容的分享会恢复到新的分支和工作目录，不会覆盖当前目录。
4. 只有会话内容的分享会创建一个普通文件夹，并写入 `HANDOFF.md` 和 `handoff.json`。
5. 用户确认后，可以从该目录打开 Claude Code，或请求官方 ChatGPT 应用打开一个新任务。

Relay 不会把原聊天伪装成 Claude Code 或 ChatGPT 的原生历史。新任务会先读取交接文件，然后继续处理工作。

## 常见问题

### 能直接把 Claude Code 会话导入 ChatGPT 吗

不能直接导入原生聊天历史。Relay 会把双方都能理解的聊天记录和项目说明整理进分享包。接收者可以在 ChatGPT 中开始一个新任务，并让它先读取 `HANDOFF.md`。

### 能导入 Claude 或 ChatGPT 官方生成的网页分享链接吗

目前不能。厂商网页分享通常只包含可见对话，不能提供完整工具记录、附件原件和 Git 修改。当前支持范围见 [外部分享链接说明](docs/provider-share-links.md)。

### 接收分享后会自动运行命令吗

不会。安装依赖、运行测试、执行工具调用、更新 submodule 和下载 Git LFS 文件，都必须由用户自行决定。

### 项目不是 Git 仓库还能分享吗

可以。Relay 会自动取消 Git 内容，只分享会话和项目说明。接收时会创建普通文件夹，不要求准备 Git 仓库。

### 分享链接有访问密码吗

完整链接本身就是读取凭据。任何拿到链接的人都可能读取内容。请只把链接发送给需要查看的人，并在不再需要时撤销分享。

## 当前状态

Relay 目前面向 macOS，处于早期版本。

- 已支持读取本机 Claude Code 和 ChatGPT 会话。
- 已支持普通文件夹和 Git 项目。
- 已支持加密分享包、本机导入和 HTTPS 分享链接。
- 已支持接收者在浏览器中查看聊天记录和交接说明。
- ChatGPT 继续任务功能要求安装通过签名检查的官方 ChatGPT 应用。
- 应用签名、公证、正式分享域名和发布版安装测试仍需在公开发行前完成。

不要把当前早期版本用于无人检查的敏感代码分享。

## 安全说明

- 每个分享包使用独立密钥加密，分享服务只保存密文。
- 解密密钥放在链接的 URL fragment 中，通常不会随 HTTP 请求发送给服务器。
- 接收内容必须先通过格式、大小、摘要和路径检查，之后才能写入本机目录。
- Relay 不读取环境变量、钥匙串、SSH 配置或 Git 凭据作为分享内容。
- 工具调用始终是历史记录，不会进入执行队列。
- 失败的 Git 恢复不会强行删除新建目录，避免误删用户文件。

详细规则见 [安全说明](docs/security.md)。

## 本地开发

如果你只是想使用 Relay，可以跳过这一节。

需要准备：

- macOS
- Node.js
- pnpm 11
- Rust 1.77.2 或更高版本
- Go 1.24 或更高版本
- Git

安装依赖并运行主要检查：

```bash
pnpm install --frozen-lockfile
pnpm check
```

启动桌面开发版：

```bash
pnpm desktop:dev
```

构建当前机器架构的 `.app` 和 DMG：

```bash
pnpm desktop:build:local
```

检查构建结果：

```bash
pnpm desktop:verify src-tauri/target/release/bundle/macos/Relay.app
pnpm desktop:verify src-tauri/target/release/bundle/dmg/Relay_0.1.0_aarch64.dmg
```

只运行前端界面：

```bash
pnpm dev
```

浏览器开发模式使用演示数据。读取真实会话、生成分享包和恢复 Git 内容必须在桌面应用中测试。

Cloud 分享服务的开发和测试命令：

```bash
pnpm cloud:check
```
